  - type: overview
    title: 概览
    body: |
      把 桑多涅 的立绘拆成带透明通道的部件，用开源网页骨骼 Iki 绑定，做成浏览器里能待机的人物。目标是眨眼、呼吸、头发和披风轻摆，鼠标带动头部和眼睛，再能点几下短动作。

      选型时对照过博客角落那种 Live2D 挂件：那些模型是 Cubism 的 .moc3，要官方编辑器导出。这边没有走那条路，改用 MIT 协议的 Iki（WebGL2，模型是明文 JSON 的 .iki）。当前做到 v010：手臂、手肘、腿和下蹲都有参数。制作工程在独立仓库，本站只托管播放页。
  - type: markdown
    title: 为什么是 Iki
    body: |
      | 方案 | 结论 |
      |------|------|
      | Live2D Cubism `.moc3` | 需要官方 Cubism Editor 导出，纯脚本交不出完整网页模型 |
      | 论文里的自动分层管线 | 没有能在本机跑起来的权重 |
      | 大模型分层 | 显存需求远超这台笔记本 |
      | **Iki**（`@ikijs/*`） | 选定。角色部件 PNG 自动绑定，再在网页里播放 |

      播放器钉死在 `@ikijs/engine` 0.6.1、`@ikijs/format` 0.8.0。绑定用 `@ikijs/editor` / `@ikijs/mcp` 0.23.0。Iki 还是 0.x，这几个版本不能随手升级。

      自动绑定至少要有脸、左右眼、嘴。头发、眉、睫毛、虹膜、身体、袖子按需要补。左右是角色自己的左右：角色的左眼在画面右侧。
  - type: markdown
    title: 现在能做什么
    body: |
      网页是整页人物，不是嵌在文章角落的挂件。模型文件是 `sandoren.iki`。

      - **待机**：眨眼、呼吸，头发有弹簧，会慢一点跟上再收回
      - **看向鼠标**：头、五官和手臂绕肩跟着转；手肘不动；腿和鞋不挂在身体形变上，所以身体转的时候腿不跟着晃
      - **表情**：微笑、大笑、生气、难过、惊讶、害羞、犯困。点一次保持，再点恢复。幅度收得很小，避免眼睑和五官被网格拧变形
      - **短动作**：点头、摇头、歪头、鞠躬、打招呼、瞥一眼、叹气、下蹲。动作用弹簧先冲过再收回。播放时鼠标暂时不抢头部
      - **界面**：表情和动作默认收在左侧「展开功能」里；「参数」固定在右上角。点「下蹲」会先弹出说明：没有单独膝关节，效果较差，确认后才播放
      - **台词**：按钮旁边有一句偏冷、嘴硬的短句，没有头顶气泡，也不能换人、换装或拍照

      转头时两条手臂会错开摆：落在后面的那只幅度更大、稍晚动，靠近转向的那只只轻轻带一下。腿和鞋不挂在身体形变上。下蹲时头、上身和裙子一起降低，膝盖向外弯，脚留在原地。袖子画在围裙前面、上身后面，肩和肘可以分开转。

      素材按版本只追加。v000 留下原图（约 592×1271）。中间换过抠图、See-Through PSD 和 `sandoren_v2.psd`；鼻子和嘴曾经是一块半透明色框，后来画进脸的贴图，单独图层不再叠上去。v008 存过一版用来对照成品挂件，之后的动作和肢体都是在那之后加上的。

  - type: markdown
    title: 还没做到的
    body: |
      原图分辨率有限，放大补不出商业级的眼珠细节。立绘没有单独的闭眼、张嘴第二套画，眨眼靠眼睑折叠，张嘴幅度很小。腿部没有独立膝关节，下蹲只能近似。角色目前是整页人物，还没有做成博客角落那种挂件。
