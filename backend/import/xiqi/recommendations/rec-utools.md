[uTools](https://www.u-tools.cn/) 是我 Windows 上常驻的效率入口。核心理念是「一切皆插件」：装一个主程序，需要什么能力再去插件市场里按需加，不会把桌面堆满独立小软件。

**我常用的场景**

- **Alt + Space 全局搜索**：不用切窗口，直接搜插件、打开本地文件、跑一条命令。
- **剪贴板 / 翻译 / JSON 格式化**：写 wiki、改脚本时随手调用，比专门开网页快一截。
- **插件生态够大**：官方称已有 3000+ 插件，常用的小工具基本都能搜到；偶尔缺的功能也可以等社区补全，或者自己写插件。

**和 AI 工作流的关系**

uTools 也在往 Agent 方向走——通过 MCP 等能力，让 Claude Code、Cursor 这类工具能调用本地插件。对我这种「编辑器 + 一堆 CLI + 浏览器」混用的习惯来说，多一个统一调用面挺有价值。

**适合谁**

- 不想为每个小需求单独装 App，又希望有一个固定唤起方式的人。
- 已经习惯快捷键驱动、愿意花十分钟逛插件市场做初始配置的人。

官网免费下载，跨 Windows / macOS / Linux。装好先挑 5～10 个插件就够日常用了，别一上来全装。
