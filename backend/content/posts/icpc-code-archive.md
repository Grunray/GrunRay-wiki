## 这是什么

[icpcCode](https://github.com/Grunray/icpcCode) 是以前打算法竞赛、刷题时堆起来的个人代码库。描述只有一句 *own test files*——说白了就是**练习场 + 半成品模板**，不是整理过的题解站。仓库 **2025-11-02** 建好，最后一次推送大约在 **2026-04-11**；中间提交很少，多半是整包同步。

乱是预期内的：文件夹命名随手、重复题解、`.cph` 配置文件混在源码旁。对我自己够用；对外公开只是留个快照。

## 顶层大致长什么样

| 目录 | 内容印象 |
|------|----------|
| `Leetcode/` | 按题号命名的 C++ 题解（如 LRU、LFU、最长回文子串等） |
| `MyCCode/` | C / C++ 主战场：模板、题解、图与字符串专题、实验 |
| `MyJavaCode/` / `MyPythonCode/` / `MyWebCode/` | 其它语言与 Web 练习 |
| `Tinatisai/` / `educoder/` | 平台作业或实验相关 |
| `UML/` | 图示材料 |
| `GitHub推送指南.md` | 当时怎么把本地堆同步到 GitHub 的笔记 |

`MyCCode` 里还能再拆一层，例如：

- `AAA_final/` — Graph、String、综合 final
- `MyCodeTemplate/` / `MyCodeSolve/` — 模板与题解
- `Codefields/` — OJ / helloworld 一类入门脚手架
- `算法实验/`、`tiantisai/`、`hltv_BigMajor/` 等专题或兴趣向小项目

## 怎么用这份仓库

- **当考古**：找回某次做过的题或某段字符串 / 图论草稿，比从零写快。
- **不当教材**：命名、目录、注释都没有统一规范；抄模板前先自己跑一遍。
- **和本站算法文的关系**：站上成体系的字符串模板（KMP、SAM、PAM 等）是另写并导入的；icpcCode 更偏「当时现场留下的痕迹」。

若只想看结构，打开仓库根目录按上表点进去即可。需要整洁题解时，更适合去本站已整理过的算法系列，而不是直接 fork 这个堆。
