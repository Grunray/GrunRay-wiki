# E · 图文合组

入口 `index.html`。单套静态 HTML；直接双击可预览。顶部可回看原有 B / D，不更改 v1 / v2 或总入口。

原型只验证首页首屏。导航文字与工具是位置示意；回看链接及图文间距滑杆可用。人物原 SVG 与站点字体沿用仓库素材，无构建与后端依赖。

## 调整方法

- 原布局把文案独立放左侧，图片独立贴右；横屏变宽时，图宽仍受首屏高度约束，中间距离跟着增大。
- 这里把文案与插画放入同一正常布局：先确定两者间距，再把整组居中。宽屏新增的余白落在组合两侧。
- 完整保留人物原图比例；不使用 A / C 的放大裁切。图边淡入从 26% 缩短至 14%，减少图片框内部的透明区。
- 刊头、底边与封面故事仍通栏；整组居中只作用于舞台内的图文。没有增加中缝、常驻动画或装饰图形。
- 小屏上下排，图片完整放在文字上方，隐藏刊号与旁注。滑杆仅用于桌面横排的间距对比。

复用 `v1/styles.css` 的纸面令牌与公共结构；本版覆盖只在 `v3/`。

## 检查

已在内置浏览器检查 1280×720、1920×1080、390×844：文案与原图可见，无横向溢出；滑杆的 16px / 112px 两端能同步更新间距与读数；回看 B 链接进入原版 B。脚本通过 `node --check`。
