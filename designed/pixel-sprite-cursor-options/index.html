方案 B · 像素解构 Morph 移动时 Sprite → 色源方块散开；停下后重新聚合为完整角色。视觉语言完全来自图中墨 / 紫粉 / 月灰，比贴图跟随更「高级」。 实现与性能成本中等。 SPRITE → PIXEL → SPRITE

方案 C · Pixel Companion 完整层 Layer1 热点像素 + Layer2 惯性角色 + Layer3 短命色源拖尾 + Layer4 交互态（Hover 偏转 / Click 爆散 / Text 细线光标）。 对应提示词里的最终体系；默认仍克制，只在交互时明显。 DEFAULT · MOVE · HOVER · CLICK · TEXT
