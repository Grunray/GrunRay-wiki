⑦ 实验结论（2026-10-11）

多轮采样迭代后的定型判断，作为合并决策依据

锚点 Damselette → 点阵化：直接可用。16×16 @ 15px 叶片/笔尖方向感完整。 迭代修正：锚点是 stroke 线条稿，面积采样会让暗档倒挂（暗 50 / 主 9）——按件独立 TUNE （线条稿 → 峰值采样 t0=0.14 + t2≈1 不分高光档）后主色 114 绝对主导。
Kuuhenki → 点阵化：可用。同峰值修正，16×16 @ 15px 主 111 / 暗 3 / 光 4； 静止组合（④ 区 D：sleep 位图 + 粒子雨）里点阵版与位图版几乎无差别。
Columbina 主图 → 36px 不可行，56px 可行。复杂插画在 36px（cell 1.29px）下点阵糊成一团； 56px（cell 2px）+ 面积采样 t0=0.30 + 去孤立点后，翅膀少女剪影清晰可辨、三色分层有效（主 179 / 暗 90 / 光 73， 高光自然落于头/翼亮区）。代价：光标主图变大（36 → 56px），SCHEMES.d.spriteMaxPx 与偏移需同步调。
sleep 静止图 → 未采样。同为复杂场景插画（40px），结论同 Columbina：点阵化需 64px+ 或保留位图； 其银河粒子雨与点阵语言天然兼容，保留即可。
拖尾月相 → 真实尺寸点阵化可行但需饱满化渲染。r 3.2~5.2px 时 dot 仅 0.3~0.4px， 直接渲染会「虚」；dot 半径 ×1.4（cellPx×0.58）+ 盘体 alpha ×1.7 后颗粒感与月相形态兼具（见 ④ 区 B/C）。
