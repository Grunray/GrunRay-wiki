一只蜗牛
- 可以有爬行动画
- 可以是一个线条状的植物然后变换成蜗牛
- 鼠标长时间不动，可以吃掉卡片中的文字

整体的动画路线： 水滴从天而降滴落在带有螺旋线条的植物上 -> 螺线线条的终点探出蜗牛的头和尾巴（也就是整个身体） -> 从植物上爬下来 -> 缓慢的爬行  -（如果爬行到有文字的区域）> 吃掉文字。

螺旋线就是蜗牛的壳。
螺旋线条的植物：拆分成两部分，螺旋线、植物的本体。
蜗牛：螺旋线，蜗牛的身体。

技术上可实现，但属于「中高复杂度」的 SVG 交互动画，不是几行 CSS 能搞定的那种。

基础爬行动画：不难。用 GSAP 或 SMIL/CSS + transform 做蜗牛身体位移、触角摆动、壳轻微弹性就行。
植物线条变蜗牛：中等偏难。核心是 path morph（路径变形），要求植物路径和蜗牛轮廓路径点数/拓扑尽量匹配，通常会用 GSAP MorphSVG 或手工做多段过渡。
“探出头尾”过渡：中等。可以拆层（壳、身体、头、尾）做遮罩和路径绘制，视觉上很自然。
长时间不动触发行为：简单。监听 mousemove，加 idle 计时器（比如 3~5s）即可。
吃掉文字：中等偏难。
简化版：吃到区域后整段文字淡出/擦除。
进阶版：按字逐个“被吃掉”，需要文字拆分（span 或 SVG text），并和蜗牛位置做碰撞判断。
总体难点
路径变形质量（最容易做“僵硬”）
时间轴编排（从植物→蜗牛→下爬→巡航→吃字）
交互状态机（hover/idle/离开/重复播放/中断恢复）
我建议的实现路线（稳妥）
技术栈：SVG + GSAP (MotionPathPlugin + MorphSVG/或 flubber) + JS 状态机
分阶段做：
先跑通蜗牛独立爬行
再做植物→蜗牛变形
再加 idle 检测
最后加吃字逻辑（先区域淡出，再升级到逐字）
如果卡片很多，注意性能：只在 hover 时启动动画，离开后暂停/重置。
