# 纸上来信 · v1 存档

本目录冻结已确认的第一版效果。为使存档独立可用，人物 WebP 与三份字体已复制到 `assets/`，HTML / CSS 只相应改了资源路径；动画代码与时序保持原样。后续迭代位于相邻的 `../v2/`，不在本目录继续修改。

单套方案，入口为 `index.html`。在完整仓库中双击即可预览，不需要安装依赖、启动后端或运行 Vue。

分镜：封签（0–2.1 秒）→ 起笔（2.1–6 秒，人物面部向外描绘）→ 落版（6–9.3 秒，线稿交接 WebP）→ 开卷（9.3–12 秒，落到欢迎首屏）。这是演出进度，不模拟网站资源加载。自动播放一遍后停住。

支持重播、暂停、进度拖看、分镜跳转、Esc 跳过、空格暂停 / 继续、沉浸预览，以及浅色 / 深色 / 抽象主题。降级与最简档直接显示终帧；系统减少动态优先于原型的“完整”选项。切后台会暂停。

视觉以 `docs/DESIGN.md` 为准：纸底 `#f4f1e8`、墨 `#2b2823`、浅色唯一强调色 `#2e6b4f`。注意现有 `tokens.light.css` 的 accent 与文档有差异，本原型遵从用户指定的 DESIGN.md，不改生产令牌。

人物原图来自 `frontend/public/art/polonia_sandoren.webp`，已原样保存在 `assets/`。`line-art.js` 是 `frontend/public/art/polonia_sandoren_line.svg` 的原样字符串封装，供 `file://` 无 fetch 限制地描绘 354 条原有路径；未重绘人物、未改动原素材。标题字体来自 `frontend/public/fonts/`，亦已在本目录归档。

这里只演示动画及一个落幕首屏，无真实路由、账号授权、加载任务、音频或主站接入。`frontend/src` 保持不动。
