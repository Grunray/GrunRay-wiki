# 纸上来信 · v3 细部构形

入口 `index.html`，可直接双击离线预览。顶部可回看 `../v2/index.html` 的冻结版本，v1 / v2 本次均不修改。

保留 v2 的 12 秒单套分镜、纸面排版与终帧，在原有打型骨架上细化：

- **面部**：头颅经纬 / 额骨块面、近远眼眶及眉弓、鼻梁楔体 / 鼻底截面、颧骨侧面、口吻与下颌。
- **颈肩**：颈部圆柱截面、斜肌、锁骨与肩部的衔接。
- **躯干**：胸腔横截面与纵向经线、胸骨与肋部转折、腰腹收束、相对倾斜的骨盆截面与块面。
- **四肢和机械物**：上臂 / 前臂截面、掌部体块与指骨走向，机械圆盘的同心截面与铰链体积轴。

线条按主结构、块面边缘、测量细线、排线分级；新增细节仍只用次要墨色，主动态线保留唯一强调色。无新增全屏网格或常驻装饰。

- **1.75–3.4 秒，搭骨架**：机械物的透视延长线、头颅椭圆与五官比例线、头颈至腰腹的动态主线。
- **2.4–4 秒，立体积**：胸腔蛋形与块面、肩肘腕的圆柱截面、腰腹块体，以及机械圆盘的透视椭圆；少量排线提示转折。
- **2.28–4 秒，细分体面**：面部先起，颈肩与躯干随后，四肢与机械细节补齐。
- **3.45–6.15 秒，描正稿**：让细节先有可见停留，再从面部向外描原人物的 354 条路径。
- **4.4–6.55 秒，收辅助线**：动态线先退，比例与体积线随后淡去；6.2 秒开始交接 WebP，6.55 秒辅助线完全清空。
- **9.3–12 秒，开卷**：保持 v1 的欢迎首屏与自然落幕。

辅助 SVG 与原人物共用 `1536 × 1024` 画布、等比裁切、缩放和移动端遮罩。它是按原插画手工布局的绘画演出辅助层，不代表自动识别人像或实际建模。线色只使用主题的次要墨色与唯一强调色，不铺全屏网格。

支持重播、暂停、进度拖看、分镜跳转、Esc 跳过、空格暂停 / 继续、沉浸预览，以及浅色 / 深色 / 抽象主题。降级与最简档直接显示终帧；系统减少动态优先于原型的“完整”选项。切后台会暂停。

视觉以 `docs/DESIGN.md` 为准：纸底 `#f4f1e8`、墨 `#2b2823`、浅色唯一强调色 `#2e6b4f`。注意现有 `tokens.light.css` 的 accent 与文档有差异，本原型遵从用户指定的 DESIGN.md，不改生产令牌。

人物 WebP 与三份站点字体已独立保存在 `assets/`，来自原有 `frontend/public/` 素材。`line-art.js` 封装原人物 SVG，354 条正稿路径保持原样。所有新增线条都在同一 WAAPI 时间轴上，暂停、拖看、重播、跳过均同步；结束后撤下临时层。v1 / v2 保持冻结。

这里只演示动画及一个落幕首屏，无真实路由、账号授权、加载任务、音频或主站接入。`frontend/src` 保持不动。
