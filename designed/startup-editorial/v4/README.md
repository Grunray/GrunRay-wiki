# 纸上来信 · v4 铅笔底稿

入口 `index.html`，可直接双击离线预览。顶部可回看 `../v3/index.html` 的冻结版本，v1 / v2 / v3 本次均不修改。

在 v3 上移除面部辅助线，并增加独立的铅笔底稿阶段。为让底稿成形后有可见停留，总时长延长到 16 秒。

- **面部**：删掉头颅 / 五官比例、面中轴、颧颌块面等打型图形；全体辅助线共用头脸留白遮罩，透视延长线也不会穿脸。真实五官随铅笔稿和墨线正常出现。
- **身体**：保留颈肩、胸腹骨盆、四肢和机械物的打型细节；铅笔阶段保留为较浅底线。
- **铅笔稿 / 下書き**：按同一人物原 SVG 的几何轮廓采样，生成灰色轻线；固定的细小偏移、少量非面部试探复笔、局部浅排线区分于正式墨线。不是将最终图直接变灰。
- **描墨**：铅笔轮廓全部画完并停留后，才绘制原人物的 354 条正稿路径；底稿和辅助线随后淡去。

线条按主结构、铅笔轻重、试探复笔、正式墨线分级。铅笔稿只用主题的次要墨色，身体动态线沿用唯一强调色；不叠面部几何网格。

- **0–2.1 秒，封签**：保留原开场。
- **2.1–4.6 秒，身体打型**：先完成全部结构线，不绘制面部定位。
- **4.6–8.2 秒，铅笔底稿**：按面部至周边的顺序轻描轮廓，补入少量复笔和排线；底稿完整后停留，辅助线留在底下。
- **8.2–11.1 秒，正式描墨**：沿底稿描墨，辅助线在 10.2 秒前清空，铅笔层在 11 秒淡净。
- **11.1–13.5 秒，落版**：交接 WebP 原图。
- **13.5–16 秒，开卷**：落到欢迎首屏并停住。

辅助线、铅笔稿、正稿与 WebP 共用 `1536 × 1024` 画布、等比裁切、缩放和移动端遮罩。铅笔几何只在初始化时计算一次；重播和拖看复用同一时间轴，不随机抖动或重复生成图层。

支持重播、暂停、进度拖看、分镜跳转、Esc 跳过、空格暂停 / 继续、沉浸预览，以及浅色 / 深色 / 抽象主题。降级与最简档直接显示终帧；系统减少动态优先于原型的“完整”选项。切后台会暂停。

视觉以 `docs/DESIGN.md` 为准：纸底 `#f4f1e8`、墨 `#2b2823`、浅色唯一强调色 `#2e6b4f`。注意现有 `tokens.light.css` 的 accent 与文档有差异，本原型遵从用户指定的 DESIGN.md，不改生产令牌。

人物 WebP 与三份站点字体已独立保存在 `assets/`，来自原有 `frontend/public/` 素材。`line-art.js` 封装原人物 SVG，354 条正稿路径保持原样。所有图层共用 WAAPI 时间轴，暂停、拖看、重播、跳过均同步；结束或降级后撤下打型、铅笔和描墨层。v1 / v2 / v3 保持冻结。

这里只演示动画及一个落幕首屏，无真实路由、账号授权、加载任务、音频或主站接入。`frontend/src` 保持不动。
