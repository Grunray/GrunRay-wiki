# 纸上来信 · 启动动画原型

入口 `index.html` 默认进入最新的 **v4**。各版本均可在浏览器中直接打开，无需后端或构建。

| 版本 | 入口 | 说明 |
| --- | --- | --- |
| v1（存档） | `v1/index.html` | 已确认的第一版：封签 → 人物线稿 → WebP 落版 → 欢迎开卷。冻结原有分镜和视觉。 |
| v2（存档） | `v2/index.html` | 在 v1 上增加比例线、动态线、体积块面与透视辅助线；先打型，再描轮廓，落版前收线。已冻结，全部文件保持原样。 |
| v3（存档） | `v3/index.html` | 在 v2 上细化头颅经纬、眼眶鼻颌、颈肩、胸腔、腰腹骨盆、四肢与机械截面。已冻结。 |
| v4 | `v4/index.html` | 去掉面部打型与穿脸透视线；身体打型完成后绘制灰色铅笔底稿，完整停留后再描墨、落版。总长 16 秒。 |

每个版本独立保存脚本、样式、人物 WebP 与所用字体；`line-art.js` 内含同一人物原始 SVG。v1 / v2 / v3 均为冻结存档，后续只迭代新版本。v1 仅为独立存档调整了资源引用路径，视觉与播放时序保持原样；每次新建版本前后核对旧版全部文件 SHA256，保证存档不变。

所有迭代只位于 `designed/`，未接入 Vue 生产代码。视觉遵守 `docs/DESIGN.md`；三档主题、动效降级、进度拖看、跳过、重播和沉浸预览保持可用。
