MESSAGES | | 与 121/122 刊头同语汇。改动量最小，推荐先看。

现状 居中渐变大标题（background-clip: text，DESIGN §3 已禁）、欢迎语玻璃卡、登录/撰写居中纸卡、留言也是左绿条卡片。对照用，不作为合入目标。

方案 A · 刊头账本 复用博客/项目的 ink 顶线、.ed-kicker、目录行。欢迎语改成题名下 dek；登录是下划线字，不再用药丸；列表去卡。适合直接改 MessagesView，改动最小。

方案 B · 两栏信笺 左栏钉住刊头与撰写，右栏是往来信。读的时候始终看得到写。桌面更像杂志沙龙；窄屏叠回单列。要改页面栅格，比 A 多。

方案 C · 登记簿 每条带 № 编号与叠年日期，像旅馆留言簿。头像缩小、登录并进 WRITE 栏。最克制、最印刷；社交登录入口最不显眼，要想一下发现成本。

方案 D · 列表刊头 从 A 抽出，改成一级页：对齐 /projects / /blog 的题名 + ink 筛选带，没有返回链。Write 用欢迎句当说明；列表上沿用 B 的 Inbox 行，去掉 Ledger 侧栏。
