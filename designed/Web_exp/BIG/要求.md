1. (其它) 一、大作业主题
大作业主题不限，可根据个人兴趣、课程学习情况或实际需求自行选题，但项目应具有一定实用性或完整应用场景，不能只是简单的静态页面展示。

项目可以是纯前端项目，也可以通过本地JSON文件、浏览器本地存储或公开API模拟数据交互。鼓励使用Vue完成组件化开发。

二、基本要求
项目须为一个完整的前端应用，具有明确的主题、应用场景和用户对象。本次大作业可1人或多人组队完成，以下作业要求以1人一组为例，若多人组队，则项目规模、功能数量、页面数量及文档内容等应按照组内人数相应增加，即按“基本要求 × 组内人数”执行。

项目应至少包含3个以上主要功能模块，例如：首页展示、列表管理、详情查看、表单录入、数据统计、搜索筛选、登录注册模拟、个人中心、收藏管理等。      
项目页面数量不少于3个，若采用Vue单页应用形式，可通过路由实现不少于3个页面或视图。
项目应具有较完整的页面结构和交互流程，用户能够完成基本操作，而不是只能浏览静态内容。
项目应具有良好的界面设计，页面布局合理，色彩统一，具有一定美观性和可用性。
项目代码应符合前端工程规范，HTML、CSS、JavaScript或Vue组件结构清晰，命名规范，注释适当。
项目必须能够在本地正常运行，提交的源代码应包含必要的运行说明。
三、技术要求
1. HTML5要求

项目中应合理使用HTML5语义化标签，要求页面结构清晰，标签使用合理，不能全部使用无语义的div进行堆砌。

2. CSS3要求

项目中应使用CSS3完成页面布局和视觉设计，要求包括：

使用Flex或Grid完成页面布局。
页面整体风格统一，具有较好的视觉层次。
合理设置字体、颜色、间距、边框、圆角、阴影等样式。
至少使用3种以上CSS3效果，例如：
border-radius
box-shadow
transition
transform
animation
@keyframes
渐变背景
伪类选择器
页面应适配常见PC端浏览器显示效果，不得出现明显错位、遮挡、重叠等问题。
鼓励进行响应式设计，使页面在不同屏幕宽度下具有较好的展示效果。
3. JavaScript与jQuery要求

项目中应体现JavaScript基础应用能力，要求包括：

能够进行DOM操作，实现页面内容动态变化。
能够进行事件处理，如点击、输入、提交、切换、删除、添加等。
能够实现表单数据获取、校验和结果反馈。
能够实现列表动态渲染、搜索、筛选、排序或分页等功能中的至少一种。
若使用jQuery，应能合理使用选择器、事件绑定、动画效果和DOM操作。
不允许只使用静态HTML页面完成项目。
4. Vue要求

本课程包含Vue相关内容，因此大作业鼓励并建议使用Vue完成项目开发。使用Vue的项目应满足以下要求：

使用Vue创建前端应用，可使用Vue 2或Vue 3。
项目应合理划分组件，例如导航组件、列表组件、卡片组件、表单组件、详情组件等。
使用数据绑定、事件绑定、条件渲染和列表渲染等Vue基础语法。
鼓励使用Vue Router实现页面跳转。
鼓励使用Pinia或Vuex进行状态管理，但不作强制要求。
鼓励使用Element Plus、Ant Design Vue等UI组件库，但不得完全依赖组件库堆砌页面，应体现个人设计与开发过程。
5. 数据处理要求

项目应包含一定的数据处理功能，可采用以下方式之一：

使用本地JSON文件模拟数据。
使用浏览器localStorage或sessionStorage保存数据。
使用数组或对象模拟数据。
调用公开API获取数据。
使用Mock数据模拟后端接口。
项目中应至少实现以下数据操作中的两类：

数据新增
数据删除
数据修改
数据查询
数据筛选
数据排序
数据统计
数据可视化展示
四、功能要求
项目应至少包含以下功能类型中的若干项：

首页展示功能
     展示项目名称、核心功能、主要内容或数据概览。
导航功能
     能够在不同页面或不同功能区域之间切换。
列表展示功能
     能够展示一组数据，如任务列表、商品列表、文章列表、课程列表等。
详情查看功能
     能够查看某一条数据的详细信息。
表单录入功能
     能够通过表单输入数据，并进行基本校验。
搜索或筛选功能
     能够根据关键词、分类、状态、日期等条件筛选数据。
添加、修改或删除功能
     能够对页面数据进行基本管理操作。
统计或可视化功能
     能够展示数量统计、进度统计、图表或状态概览。
用户交互反馈功能
     如弹窗提示、确认框、加载状态、操作成功或失败提示等。
本地存储功能
     鼓励使用localStorage保存用户数据，使刷新页面后数据仍能保留。
五、设计文档要求
每组需提交一份实验报告。设计文档应结构完整、内容清晰，体现软件工程开发过程。设计文档应至少包括以下内容：

1. 项目概述

说明项目名称、项目背景、开发目的、目标用户和应用场景。

2. 需求分析

说明项目要解决的问题，以及用户的主要需求。

应包含：

功能需求
非功能需求，如界面友好性、易用性、兼容性、可维护性等
用户角色说明，如普通用户、管理员等，如项目不区分角色可说明为单用户使用
3. 功能模块设计

使用文字、表格或图示说明系统的主要功能模块。

4. 页面设计

说明项目包含哪些页面，每个页面的主要内容和功能。

建议配合页面原型图、页面截图或布局草图进行说明。

5. 交互流程设计

说明用户使用项目时的主要操作流程，例如：

用户进入首页
浏览数据列表
搜索或筛选内容
查看详情
新增或修改数据
保存或删除数据
查看统计结果
可使用流程图进行说明。

6. 数据结构设计

说明项目中主要使用的数据字段和数据结构。

例如任务管理系统可设计如下数据结构：

{
  id: 1,
  title: "完成前端大作业",
  category: "课程学习",
  deadline: "2026-06-10",
  status: "进行中",
  priority: "高"
}

7. 技术方案设计

说明项目采用的主要前端技术，例如：

HTML5
CSS3
JavaScript
jQuery
Vue
Vue Router
localStorage
ECharts或其他可视化库
UI组件库
同时说明这些技术分别用于实现什么功能。

8. 项目实现说明

说明项目已经实现的主要功能，并配合关键页面截图进行展示。

9. 总结与不足

说明项目完成情况、个人收获、存在的问题以及后续可改进方向。

六、答辩视频要求
每组需提交一份项目展示视频，用于验收答辩。

建议包含以下内容：

项目名称与人员信息
项目背景与选题意义
项目需求分析
系统功能模块
页面设计与界面展示
技术路线与开发工具
核心功能实现说明
项目运行效果展示
总结与不足

十、注意事项
大作业必须独立完成，严禁直接复制他人项目或完整套用网上模板。
可以参考开源项目或UI设计风格，但必须进行二次设计和自主实现。
若使用第三方素材、组件库或开源代码，应在设计文档或README中说明来源。
项目必须能够正常运行，无法运行的项目将影响成绩。
页面不能只是静态展示，应包含必要的交互功能和数据处理过程。
鼓励使用Vue完成组件化项目开发。
鼓励将本次大作业作为期末作品或个人作品集项目继续完善。
