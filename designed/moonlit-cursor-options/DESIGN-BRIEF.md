请重新设计并实现当前个人博客网站的全局鼠标光标拖尾效果。

## 一、项目背景

这是一个个人博客网站，整体视觉风格已经确定为：

- Editorial / Magazine / Newspaper（编辑部、杂志、报纸）风格
- 米白色/暖白色背景
- Serif 衬线字体作为主要标题字体
- Sans-serif 无衬线字体作为正文
- Monospace 等宽字体用于栏目标签、日期、VOL、NO 等信息
- 大量细线、留白、排版层级
- 整体具有「个人数字杂志 / 技术档案 / 个人出版物」的感觉
- 页面设计追求克制、优雅，而不是高饱和、高亮度、高密度的视觉特效

当前鼠标拖尾效果只是「几个字母跟随鼠标」，现在希望彻底重新设计。

本次设计以《原神》角色「哥伦比娅（Columbina）」作为灵感来源，但不要直接复制角色立绘、角色模型、官方 Logo、官方 UI、角色头像或其他受版权保护的素材。

重点提取哥伦比娅的设计气质：

- 月光
- 月相
- 羽毛
- 风
- 歌唱
- 摇篮曲
- 梦境
- 圣洁感
- 安静、柔和、神秘
- 略带诡异感
- 冷白色
- 淡蓝灰色
- 极其克制的光效

最终效果应该是「受到哥伦比娅设计语言启发的个人网站 Cursor」，而不是一个明显的「原神角色特效」。

## 二、整体设计概念

将整个鼠标系统命名为：

**Moonlit Editorial Cursor**  
月下编辑光标

核心概念：

「鼠标移动时，像有一阵非常轻的风吹过纸面，留下月光、羽毛和歌声的痕迹。」

不要做成普通的粒子拖尾。

不要做成霓虹光效。

不要做成大量二次元粒子。

不要做成发光鼠标。

不要做成明显的原神 UI。

要让效果与当前网站的 Editorial / Newspaper 风格融合。

最终视觉应该像：

「一份安静的、带有梦境感的旧报纸，在鼠标经过时留下了月光和羽毛。」

## 三、最重要的视觉原则

### 1. 克制

所有效果必须轻量、低透明度、低饱和。

鼠标特效不能抢过：

- Hero
- 文章标题
- Project
- ABOUT
- 导航栏

鼠标特效是辅助交互，而不是页面主视觉。

### 2. Editorial 风格

所有图形尽量使用：

- 极细线条
- 线稿
- 简单几何
- 少量羽毛轮廓
- 月牙/月相轮廓
- 少量音符
- 微弱粒子

不要使用：

- 大面积 Glow
- 强 Bloom
- 彩色火焰
- 大量粒子
- 大型 3D 模型
- 大型发光圆球
- 大量图片
- 明显的游戏 UI

### 3. 不要直接复刻哥伦比娅

只借鉴：

- 月光
- 羽毛
- 歌声
- 梦境
- 冷白
- 淡蓝灰
- 神秘感

不要出现：

- 哥伦比娅人物立绘
- 哥伦比娅头像
- 原神 Logo
- 愚人众 Logo
- 官方角色素材
- 官方 UI 素材

## 四、鼠标核心设计

普通状态下，鼠标核心不要使用普通圆点。

设计成一个非常小、极简的「月牙核心」。

视觉参考：

```
    ·
   ◔
```

或者：

```
      ·
     ◔
```

核心由：

- 一个极细的月牙
- 一个非常小的中心光点

组成。

尺寸：

- 月牙约 8～12px
- 中心点约 2～3px

默认状态：

- 非常淡
- 不要明显发光
- 不要产生巨大阴影
- 不要影响文字阅读

鼠标停止移动后，核心也保持存在，但透明度降低。

## 五、鼠标移动拖尾

鼠标移动时，不再显示字母。

改成：

「月光曲线 + 羽毛 + 微粒子」

三个部分组成。

### 第一部分：月光曲线

鼠标移动时生成一条非常细的、带惯性的曲线。

例如：

```
          ╭────╮
       ╭──╯    ╰──╮
    ╭──╯            ╰──●
```

要求：

- 线条非常细
- 透明度低
- 不要形成明显的粗线
- 有轻微惯性
- 鼠标快速移动时曲线稍微拉长
- 鼠标慢速移动时曲线缩短
- 鼠标停止时曲线快速淡出

不要让曲线一直永久存在。

### 第二部分：羽毛

沿鼠标轨迹随机生成非常少量的「极简羽毛线稿」。

不要生成完整、复杂的羽毛。

只需要简单轮廓。

例如：

```
      ︵
     ╱ ╲
    ╱   ╲
     ╲  ╱
      ╲╱
```

羽毛要求：

- 约 5～12px
- 极低透明度
- 随机旋转
- 随鼠标运动方向产生轻微偏转
- 出现后逐渐淡出
- 有轻微漂浮
- 有轻微旋转
- 不要同时出现太多

默认情况下屏幕上同时存在的羽毛数量控制在很低的水平。

建议：

`MAX_FEATHERS = 8～15`

根据性能动态调整。

### 第三部分：微粒子

只使用极少量微粒：

- 小圆点
- 极小短线
- 极小菱形

不要大量粒子。

粒子应该像：

「纸面上残留的一点墨迹 / 月光」

而不是：

「游戏粒子特效」。

## 六、鼠标速度响应

根据鼠标移动速度动态调整效果。

慢速移动：

```
◇──◇──●
```

效果：

- 拖尾短
- 羽毛少
- 粒子少
- 线条淡

正常移动：

```
      ︵
         ·
            ︵
               ◔
```

效果：

- 中等长度拖尾
- 少量羽毛
- 少量粒子

快速移动：

```
︵       ︵
      ·       ︵
             ─────────●
```

效果：

- 拖尾稍长
- 羽毛数量稍微增加
- 羽毛漂移距离增加
- 月光曲线更加明显

但是无论多快，都不能产生大量粒子。

## 七、羽毛的运动方式

羽毛不能简单地跟随鼠标坐标。

必须有独立的运动状态。

羽毛生成后：

1. 根据鼠标当前速度确定初速度
2. 根据鼠标移动方向确定主要运动方向
3. 加入轻微横向随机偏移
4. 加入轻微重力/下坠
5. 加入轻微旋转
6. 透明度逐渐降低
7. 最终销毁

效果应该类似：

```
鼠标 →

︵
   ↘
      ︵
         ↘
            ◔
```

而不是：

```
鼠标 →

︵︵︵︵︵●
```

## 八、Hover 交互

当鼠标进入：

- 文章链接
- Project
- 导航按钮
- 可点击元素

时，鼠标核心发生变化。

默认：

```
    ◔
```

Hover：

```
     ╭──╮
       ◔
     ╰──╯
```

设计成「月相变化」。

默认月牙：

`◔`

Hover 后逐渐变成：

`◑`

最终可以接近：

`●`

但不要真正变成一个巨大的实心圆。

动画持续约：

200～300ms

离开 Hover 区域时反向恢复。

## 九、文章 Hover

当鼠标进入文章链接时：

- 月牙稍微变亮
- 出现一圈非常细的月环
- 月环只显示 30%～50%
- 月环缓慢旋转
- 周围出现最多 1～2 个微小羽毛/粒子

示意：

```
       ╭───────╮
     ╱           ╲
    │      ◔      │
     ╲           ╱
       ╰───────╯
```

不要使用完整粗圆环。

不要使用强发光。

生产合入（方案 D）：文章链接 / 首页目录行（`.toc-row`）走 **link** 调参——虹月近读、三轨内收。见 `frontend/src/cursor/moonlitCursorConfig.ts` 的 `CONSTELLATION_HOVER_TUNING.link`。

## 十、Project Hover

Project Hover 时，可以加入非常轻微的几何反馈。生产合入：项目卡 / `.timeline-card` 走 **project** 调参——同一虹/恒/霜三月，外张、霜月更清楚（`CONSTELLATION_HOVER_TUNING.project`）。对齐 `DESIGN.md` §9 可点击卡比目录行多一层几何。

例如：

```
       ◇
     ◇ ◔ ◇
       ◇
```

四个极小菱形围绕鼠标核心。

动画：

- 展开
- 轻微旋转
- 停留
- 鼠标离开后收回

整个过程非常快。

约：

200～350ms

这只是交互反馈，不要变成大型特效。

## 十一、点击效果

点击时不要做传统的「粒子爆炸」。

做成：

「羽毛散开 + 月相扩散」。

示意：

```
             ·
          ︵     ︵
             ◔
          ︵     ︵
             ·
```

点击后：

- 2～4 个小羽毛向外扩散
- 一个非常细的月环快速扩张
- 1～3 个微粒向外移动
- 所有元素快速淡出

持续：

300～450ms

动画应该像：

「一阵风吹散羽毛」

而不是：

「能量爆炸」。

## 十二、快速移动彩蛋

当鼠标高速移动时，低概率生成一个非常短暂的音符。

例如：

```
        ♩
       ·
          ╲
            ·────●
```

音符：

- 尺寸 5～9px
- 低透明度
- 只存在 300～500ms
- 有轻微向上漂浮
- 然后淡出

出现概率必须非常低。

建议：

3%～5%

不要连续生成。

目标是让用户偶尔发现：

「刚才是不是出现了一个音符？」

而不是让整个页面一直充满音符。

## 十三、停止移动

鼠标停止移动超过约 100～200ms 后：

- 月光曲线开始淡出
- 羽毛继续轻微漂浮
- 粒子淡出
- 最后只保留鼠标核心

羽毛不要瞬间消失。

应该有轻微的「落下」感觉。

## 十四、颜色体系

必须适配当前博客的米白色 Editorial 主题。

建议颜色方向：

基础：

- 暖白
- 米白
- 冷灰
- 灰蓝

强调：

- 非常淡的蓝
- 非常淡的银色
- 极少量淡金色

不要使用高饱和度颜色。

不要使用：

- 霓虹蓝
- 霓虹紫
- 高饱和粉
- 高亮青
- 强金色

建议透明度整体偏低。

大部分效果应该处于：

`opacity 0.15～0.6`

不要让整个鼠标效果比页面正文更亮。

## 十五、与网站整体风格融合

必须遵守以下原则：

网站本身：

- Editorial
- Magazine
- Newspaper
- Digital Archive
- Personal Journal

鼠标效果：

- Moonlight
- Feather
- Wind
- Lullaby
- Dream
- Quiet
- Mysterious

最终应该形成：

「月光下的个人数字报纸」

而不是：

「原神主题网站」。

## 十六、性能要求

这是非常重要的一部分。

不要使用：

- 每次 mousemove 创建 DOM
- 大量 div 粒子
- 大量 span
- 大量 Vue 响应式数据
- setInterval 创建动画
- 每帧修改大量 DOM
- 不断 appendChild/removeChild
- 大量 ResizeObserver
- 多个 requestAnimationFrame 循环

必须优先使用：

「单一全屏 Canvas + 一个 requestAnimationFrame 渲染循环」。

建议结构：

```html
<body>
  ...
  <canvas id="cursor-effects"></canvas>
</body>
```

Canvas：

- `position: fixed`
- `inset: 0`
- `width: 100vw`
- `height: 100vh`
- `pointer-events: none`
- `z-index` 根据网站实际层级确定

所有：

- 月光曲线
- 羽毛
- 粒子
- 月环
- 点击效果

全部尽可能绘制到同一个 Canvas。

鼠标位置只保存到普通 JS 状态，不要放入 Vue 响应式系统。

不要让每一次 mousemove 都触发 Vue component update。

使用：

`requestAnimationFrame()`

作为唯一动画循环。

## 十七、性能控制

必须加入：

- 粒子数量上限
- 羽毛数量上限
- 生命周期
- 自动销毁
- 根据鼠标速度动态调整生成频率
- 页面不可见时暂停动画
- `document.hidden` 时暂停 requestAnimationFrame 逻辑
- 移动端默认关闭完整鼠标效果
- touch 设备不运行完整 Cursor 系统

建议：

```
MAX_FEATHERS = 15
MAX_PARTICLES = 25
MAX_TRAIL_POINTS = 40
```

具体数值可以根据现有项目调整。

不要为了追求效果无限增加数量。

## 十八、高 DPI 屏幕

Canvas 必须正确处理：

`window.devicePixelRatio`

避免高 DPI 显示器出现模糊。

但同时要避免因为 DPR 过高导致 Canvas 实际渲染尺寸过大。

建议：

```js
const dpr = Math.min(window.devicePixelRatio || 1, 2);
```

## 十九、窗口 resize

resize 时正确重新设置 Canvas 尺寸。

不要因为 resize 导致：

- 多个 requestAnimationFrame
- 多个 event listener
- 多个 Canvas
- 内存泄漏

必须保证组件卸载时：

- removeEventListener
- cancelAnimationFrame
- 清理所有粒子数组
- 清理 Canvas context 相关状态

## 二十、移动端

移动端没有真实鼠标，因此：

- 不显示 Cursor
- 不运行 Canvas 鼠标拖尾
- 不创建鼠标粒子
- 不添加无意义的触摸拖尾

通过：

`window.matchMedia('(pointer: fine)')`

或者其他可靠方式判断是否支持精确指针。

## 二十一、可访问性

不要隐藏系统鼠标。

不要使用：

`cursor: none;`

除非你能够确保自定义 Cursor 在所有情况下都正常工作。

推荐：

桌面端保留系统鼠标，同时叠加自定义 Canvas Cursor。

如果项目原本已经隐藏系统鼠标，需要评估现有逻辑后再决定是否恢复。

必须保证：

- 文本选择正常
- 链接点击正常
- 输入框正常
- textarea 正常
- select 正常
- 拖拽正常
- 无障碍功能不受影响

## 二十二、交互层级

鼠标效果不能覆盖：

- 导航栏
- Hero
- 文章内容
- Project 卡片
- ABOUT
- Footer

Canvas 必须：

`pointer-events: none;`

它只能负责视觉表现，不能拦截鼠标事件。

## 二十三、不要修改其他页面

本次任务的核心是：

「重新设计鼠标 Cursor / Trailing Effect」。

不要因为实现这个效果而修改：

- Hero 布局
- Hero 高度
- Hero 图片滚动逻辑
- Latest
- Projects
- About
- Reread
- 导航栏
- 页面整体布局
- 字体体系

除非为了接入 Cursor 必须修改极少量代码。

特别注意：

当前 Hero 的图片滚动逻辑比较复杂。

不要修改 Hero 的 DOM 结构。

不要修改 Hero 高度。

不要修改 Hero 的图片数量。

不要修改 Hero 的滚动算法。

不要把 Cursor Canvas 放入 Hero 内部。

Cursor 应该作为全局独立层存在。

## 二十四、代码质量

请先检查现有项目：

1. 找到当前鼠标字母拖尾的实现位置
2. 找到当前 Cursor 相关 CSS
3. 找到当前全局 Layout
4. 确认使用的框架和项目结构
5. 确认是否已有 Canvas 或动画系统
6. 尽量复用已有工具和生命周期

然后再修改。

不要直接新增一套完全独立且与现有项目冲突的动画系统。

如果当前 Cursor 已经存在：

优先替换旧实现。

不要让旧的：

「字母跟随鼠标」

和新的：

「Moonlit Editorial Cursor」

同时运行。

最终只能保留一套 Cursor 系统。

## 二十五、最终视觉验收标准

完成后，请检查以下问题：

1. 鼠标静止时页面是否足够干净？
2. 鼠标慢速移动时是否优雅？
3. 鼠标快速移动时是否有明显但克制的拖尾？
4. 羽毛是否太多？
5. 粒子是否太多？
6. 是否出现明显游戏特效感？
7. 是否破坏 Editorial / Newspaper 风格？
8. 是否抢过文章标题的视觉焦点？
9. Hover 是否自然？
10. 点击是否自然？
11. 是否存在掉帧？
12. 是否出现大量 DOM？
13. 是否存在 requestAnimationFrame 泄漏？
14. 切换页面后 Cursor 是否重复初始化？
15. 浏览器窗口 resize 后是否正常？
16. 高 DPI 屏幕是否清晰？
17. 移动端是否正确关闭？
18. 输入框、文本选择、链接点击是否正常？

最终效果必须满足：

「用户第一眼不会觉得这是一个原神特效网站，但仔细观察会发现鼠标移动像月光、羽毛和歌声在纸面上留下痕迹。」

请优先保证：

视觉统一性 > 交互精致度 > 粒子数量 > 炫酷程度。

性能稳定性 > 特效复杂度。

如果某个效果会明显影响性能，请主动降低粒子数量和动画复杂度，而不是牺牲页面流畅度。
